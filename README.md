# CCNA Labs & Projects

This repository contains my hands-on **CCNA labs and networking projects**, built using **Cisco Packet Tracer**.

The labs focus on implementing and practicing networking concepts through real configurations, testing, and troubleshooting.

## Labs

* DHCP Pool Configration
* Static Routing
* Routing Protocols (EIGRP,OSPF,RIPv2)
* VLANs
* Inter-VLAN Routing
* Trunking

## Projects

Larger network scenarios that combine multiple CCNA concepts into practical network designs and configurations.

## Tools

* Cisco Packet Tracer
